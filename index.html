    ◆This site

    vienjunaid.com & the RPi Dashboard

    This site shares its engine with a full-screen home screen I run on a Raspberry Pi. Everything on the canvas is a grid of text cells: a WebGL2 glyph-atlas renderer (with a Canvas 2D fallback) draws each cell's character, foreground and background color, and half-block characters turn every cell into two stacked pixels. The scenes are procedural pixel art, drawn by code and animated at 20 fps for about 0.2 ms of CPU per frame, and the home page follows the prayer times, calculated offline in the browser. The site is plain HTML, CSS and ES modules with no build step, and one script syncs the renderer, scenes and themes over from the dashboard.
